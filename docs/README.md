## Planned documentation

The following are intended but not yet written. They are listed so the gap is visible, not
as links:

- **API reference** — endpoint-by-endpoint request and response schemas.
- **Imaging guide** — framing, distance, lighting and the printed backdrop, with worked
  examples of accepted and refused frames.
- **Model card** — training data, split strategy, calibration procedure, known failure
  modes and abstention behaviour.
- **Kit assembly** — printing the strip template, preparing reagents and running the
  two-phase printed-target validation.
- **Evaluation methodology** — how held-out splits are constructed and why splits are
  decided by session rather than by photograph.

Contributions to any of these are welcome. See [CONTRIBUTING.md](../CONTRIBUTING.md).
