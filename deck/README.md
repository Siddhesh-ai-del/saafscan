# Round 1 deck

The Tech4Food Round 1 proposal deck is generated by script. Nothing in the
`.pptx` is hand-edited, so it can be rebuilt and re-verified after the model is
retrained on real strip photos.

## Rebuild

```bash
deck/.venv/bin/python deck/bench.py         # re-measure timings -> bench.json
deck/.venv/bin/python deck/make_assets.py   # charts + screenshot crops -> assets/
deck/.venv/bin/python deck/build_deck.py    # template -> Tech4Food_Round1_SaafScan.pptx
deck/.venv/bin/python deck/verify_deck.py   # three-stage gate
```

The venv needs `python-pptx matplotlib pillow`. Rendering also needs
`libreoffice`, `poppler-utils` (`pdfinfo`, `pdffonts`, `pdftoppm`).
Rubik and DM Sans must be installed for LibreOffice to embed them:
they are in `~/.local/share/fonts/deckfonts/`.

## Where every number comes from

| File | Holds |
| --- | --- |
| `bench.json` | 6.0 ms median pipeline, 19.3 ms HTTP, 0.42 s cold start |
| `external_facts.json` | WHO and FSSAI figures with publication date and URL |
| `../models/eval_report.json` | accuracy, coverage, abstentions, confusion matrix |
| `../models/features.json`, `cnn.json` | thresholds, temperatures, hyperparameters |
| `../data/trainset/manifest.json` | sample counts and split policy |

`build_deck.py` carries a `NUMERIC_WHITELIST`; `verify_deck.py` fails the build
if any number printed on a slide has no entry there.

Note the WHO food safety fact sheet was revised on **4 June 2026**. The deck
uses 866 million illnesses and 1.52 million deaths, not the older 600 million
and 420,000 figures that are still widely quoted.

## Rules the build enforces

- the official template is copied, never edited; its sha256 is pinned and
  re-checked after every build
- all 33 chrome shapes (eyebrow, 36 pt Rubik title, footer, logos, the
  "Strictly Maintain no of slides under 9" line, and the template's swapped
  `·08` / `·07` footers on slides 7 and 8) are byte-identical to the template
- team name, lead, member names, college and contact email stay as fillable
  `[ ]` placeholders for the team to complete before export
- cost figures are labelled estimates with their basis stated
- no claim that the ML model outperforms the rule table; both scored 1.000 on
  the held-out split

## Before submitting

1. Fill the placeholders on slide 1 and slide 9.
2. `deck/.venv/bin/python deck/build_deck.py && deck/verify_deck.py`
3. Upload `Tech4Food_Round1_SaafScan.pptx` to Google Slides and export as PDF,
   or submit `Tech4Food_Round1_SaafScan.pdf` directly.
